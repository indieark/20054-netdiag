# 运行与部署说明

> 本文件维护项目如何启动、配置、构建、测试和部署。README 只保留最短入口。

## IndieArk 基线

- Node.js 项目使用 Node.js 24 或更高版本，并在 `package.json` 声明 `engines.node`。
- Python 项目使用 Python 3.12 或更高版本。
- Git 主线统一为 `main`。
- 部署端口在开发阶段保持“待定”；项目升格前必须核验飞书应用表、工作区 `PROJECTS.md` 和 GitHub 仓库名。
- 项目采用 Docker 时，生产 Compose 默认只引用 GHCR 镜像，本地 Compose 才保留 `build`；不使用 Docker 的项目按实际技术栈删除本条。
- GHCR 自动发布在项目升格为正式端口名后再启用，纯文档变更应通过 `paths-ignore` 避免触发无效镜像构建。
